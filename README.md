TANJUNG PANAS is an open-world crime game set in a fictional sun-soaked Indonesian port city. Play Raka, a getaway driver for the fixer Bu Sari: steal cars, outrun the police across a 1–5 star wanted system, and finish six story missions — deliveries, getaways and one last heist — across the Old Town market, the container port, the beach and the modern district. Three.js 3D, live minimap, traffic, pedestrians, police chases and synthesised WebAudio sound; no network needed, it runs fully offline.
## Run it
```sh
node serve.ts
```
Then open http://localhost:8080 — press ENTER to start, WASD to walk/drive, E to enter and exit cars, F to punch, Space to brake, Shift to sprint/handbrake, mouse drag to orbit the camera.
